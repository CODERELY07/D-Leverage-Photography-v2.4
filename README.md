# D-Leverage-Photography

Photography wesbite with admin.

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/CODERELY07/D-Leverage-Photography-v2.4.git
   cd D'Leverage
2. Set up the database
   Create a new MySQL database named D'Leverage.
   Copy the sql and run in your sql database 
   file:
   sql.sql

   Configure the application
   Update your database credentials in connection.php 

3. Run the project

   Place the project folder in your web server’s root directory

   Start your web server.

   Open in your browser:

   goto register.php to register the admin 

   to login go to adminLogin.php
   done.
